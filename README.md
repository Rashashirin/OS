# Operating Systems – C Programming

A collection of C programs developed while learning and practising Operating Systems concepts as part of my B.Tech in Artificial Intelligence and Data Science.

## Topics Covered

- CPU Scheduling Algorithms
- Process Management
- Operating System Fundamentals

## Programs

| Program | Description |
|---|---|
| `dev.c` | C programming exercise |
| `round_robin.c` | Round Robin CPU Scheduling |

## Technologies Used

- C Programming
- GCC Compiler

## How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/Rashashirin/OS.git
   ```

2. Navigate to the repository:

   ```bash
   cd OS
   ```

3. Compile a C program:

   ```bash
   gcc round_robin.c -o round_robin
   ```

4. Run the executable:

   ```bash
   ./round_robin
   ```

   On Windows:

   ```bash
   round_robin.exe
   ```
